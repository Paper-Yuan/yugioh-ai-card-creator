# v2.0.1 更新说明

本版本聚焦**效果设计能力**与**手机端体验**，并补齐了基于 YGOPro 全量脚本语料库的分析成果。

## 效果设计

- **代价 (Cost) 扩展**：新增 `discard_n` / `banish_gy_n` / `banish_hand_n` / `release_monster_n` / `send_to_grave_n` / `mill_deck_n` 六种带数量的代价，数量与「字段 / 卡类」均可自定义。
  其中 `mill_deck_n` 指定字段时改为从卡组挑选送墓，未指定则保持堆顶送墓；中日卡文的量词与语序分别对齐各自习惯。
- **二选一自由组合**：由原先的固定搭配改为 `choice_free`，两个分支各自设定动作、字段、卡类与数量，互不绑定。
  同时修正了一处会生成非法脚本的问题——分支筛选此前以表达式字符串传入 `Duel.*MatchingCard`，现统一生成为可调用的 Lua 函数。
- **效果外文本**：支持范围扩展到 15 项可生成脚本的规则条款（不能特殊召唤 / 不能里侧盖放 / 效果不能发动 / 不能解放 / 不能变更表示形式 / 攻击相关 / 规则上的种类·属性·种族·等级变更 / 不能作为任意召唤素材等），并新增召唤方式手续（融合 / 同调 / 超量 / 连接 / 仪式），依怪兽种类自动适配。
- **修正 nomi 语义**：原先错误使用 `EFFECT_CANNOT_SUMMON`（会连带封死自身召唤手续），已改为官方写法 `EnableReviveLimit` + `EFFECT_SPSUMMON_CONDITION(aux.FALSE)`。
- **自定义独有规则**明确标注为自由文本：仅写入卡面与 CDB，**不生成任何 Lua**，避免静默产出语义错误的脚本。

## 手机端

- 统一「上行标识 / 文本、下行填入功能」的排布：卡包工程条与向导内的输入行改为纵向堆叠，输入框独占整行、按钮换到下一行。
- 顶栏精简留白：左上角只保留标识，右侧按键改用精简标签并缩小尺寸（40→34px）。
- 步骤 4 的发布打包项改为横条状、每行一个；导出按钮同步收窄。

## 自定义字段

- 新建入口唯一收拢至**卡牌库**，制卡器内仅保留跳转按钮，移除设置页的重复管理卡片。
- 补齐模态框样式，修复此前弹窗无法正常居中弹出的问题。

## 分析与文档

- 新增 `scripts/mine-rule-texts.js`、`scripts/split-corpus-by-type.js`，遍历 [ProjectIgnis/CardScripts](https://github.com/ProjectIgnis/CardScripts) 全量 **22,739** 个卡脚本（现代 OCG 19,431），按怪兽 8,552 / 魔法 2,843 / 陷阱 2,059 切分后分别统计。
- 产出 [docs/EFFECT_CAPABILITY_CATALOG.md](EFFECT_CAPABILITY_CATALOG.md)（11 个维度、57 条能力、48 个参数、10 条 API 勘误、62 条差距）与 [docs/RULE_TEXTS.md](RULE_TEXTS.md)。

## 打包

- 构建脚本改为从 `package.json` 读取版本号，不再硬编码，避免产物版本与产品版本脱节。
- 修正 PowerShell 脚本的编码问题（补 UTF-8 BOM 并强制 UTF-8 输出），解决构建时中文文件名报「路径中具有非法字符」的错误。

## 兼容性

- 版本号 2.0.0 → **2.0.1**，Android `versionCode` 1 → 2。
- 既有卡片存档与 `.ypk` 导出格式保持兼容。
