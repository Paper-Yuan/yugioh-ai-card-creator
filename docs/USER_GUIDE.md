# 游戏王AI制卡器 v1.0.1 - 使用指南

## 🎯 优化后的使用流程

### 步骤1：填写基本信息
1. **卡片ID**：建议使用8位以上数字（如100000001）
2. **卡片名称**：输入卡片名称
3. **字段**（可选）：
   - 填写字段名（如"青眼"、"黑魔导"、"英雄"）
   - **不填写则自动归类为"泛用"卡**
4. 选择卡片类型、种族、属性等基本属性
5. 点击"下一步"

### 步骤2：制作效果脚本（三种方式）

#### 方式1：图形化编辑（推荐新手）
- 从12个效果模块中选择
- 配置参数
- 系统自动生成Lua脚本

#### 方式2：手动编写脚本（适合熟悉Lua的用户）
- 直接编写Lua代码
- 提供脚本模板
- 支持语法验证

#### 方式3：AI生成脚本
- 描述卡片效果
- AI自动生成脚本代码

选择方式后完成脚本制作，点击"下一步"

### 步骤3：上传卡图
- 点击或拖拽上传图片
- 推荐尺寸：421×614像素
- 支持JPG、PNG、WEBP格式
- 点击"下一步"

### 步骤4：生成预览
- 查看卡片预览
- 查看生成的脚本代码
- 点击"生成卡片"
- 点击"💾 保存到卡牌库"

## 📚 卡牌库功能

### 字段分类
- 自动识别卡片字段
- 未填字段的卡片归为"泛用"
- 按字段筛选查看

### 筛选功能
- **全部字段**：查看所有卡片
- **泛用卡**：查看无字段的卡片
- **具体字段**：查看特定字段的卡片（如"青眼"）
- **卡片类型**：筛选怪兽/魔法/陷阱

### 导出功能

#### 1. 导出选中卡片
1. 勾选要导出的卡片
2. 点击"📥 导出选中卡片"
3. 下载包含所有选中卡片的ZIP文件

#### 2. 导出整个字段
1. 在"字段"下拉菜单中选择字段（如"青眼"）
2. 点击"📦 导出当前字段"
3. 下载包含该字段所有卡片的ZIP文件

#### 3. 导出所有卡片
1. 进入"设置"页面
2. 点击"📤 导出所有卡片"
3. 下载JSON格式的备份文件

### 统计信息
- **总卡片数**：所有卡片数量
- **字段数量**：不同字段的数量
- **泛用卡**：无字段卡片数量
- **已选择**：当前选中卡片数量

## 📱 多平台支持

### PC端
- 推荐使用Chrome、Edge、Firefox最新版
- 分辨率建议：1280×800或更高

### 移动端（横屏）
- 旋转设备至横屏模式
- 自动适配布局
- 触控优化

## 🚀 快速开始

### 方式1：在线使用（Web版）
```bash
cd yugioh-ai-card-creator
npm install
npm run web
```
访问 http://localhost:3000

### 方式2：PC端应用（Electron）
```bash
npm run build
npm run package:win  # Windows
npm run package:mac  # macOS
npm run package:linux  # Linux
```

### 方式3：移动端应用（Android）
```bash
npm run build:mobile
npx cap sync android
npx cap open android
```

## 📥 文件输出格式

```
card_100000001.zip
├── script/
│   └── c100000001.lua       # Lua脚本
├── images/
│   └── 100000001_卡名.png   # 卡片图片
└── 100000001.cdb            # CDB数据库
```

### 字段导出（ZIP文件）
```
yugioh_青眼_xxx.zip
├── scripts/
│   ├── c100000001.lua
│   ├── c100000002.lua
│   └── ...
├── images/
│   ├── 100000001_青眼白龙.png
│   ├── 100000002_青眼究极龙.png
│   └── ...
├── 青眼.cdb                  # 包含所有该字段卡片的CDB

```

## 💡 使用技巧

### 1. 字段命名规范
- 使用简短、易识别的名称
- 示例：青眼、黑魔导、英雄、齿轮
- 避免使用特殊字符

### 2. 批量制作流程
1. 创建第一张卡片并填写字段
2. 保存到卡牌库
3. 继续创建同字段的其他卡片
4. 完成后在卡牌库中按字段导出

### 3. 效果复用
- 使用"脚本设计"保存常用效果
- 在制卡时加载已保存的脚本

### 4. 数据备份
- 定期导出所有卡片（JSON格式）
- 保存到安全位置
- 支持跨设备导入

## 🐛 常见问题

### Q: 卡片没有字段会怎样？
A: 自动归类为"泛用"卡，可以在卡牌库中筛选查看。

### Q: 如何导出整个字段？
A: 在卡牌库中选择字段筛选器，然后点击"📦 导出当前字段"。

### Q: 导出的文件包含什么？
A: 包含Lua脚本、卡片图片和CDB数据库，可直接用于YGOPro。

### Q: 图片有水印吗？
A: **完全无水印**，所有图片由Canvas生成。

### Q: 支持哪些浏览器？
A: Chrome、Edge、Firefox最新版，推荐Chrome。

### Q: 移动端如何使用？
A: 旋转至横屏模式，界面会自动适配。

### Q: 数据存储在哪里？
A: 本地浏览器（LocalStorage），安全私密。

### Q: 如何批量修改字段？
A: 暂不支持，需要逐个编辑或重新导入JSON文件。
