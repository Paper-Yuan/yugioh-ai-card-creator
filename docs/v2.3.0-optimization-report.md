## 🐛 遇到的问题及解决方案

### 问题 1：字体路径映射错误
**现象：** 打包后字体文件 404  
**原因：** 相对路径解析失败  
**解决：** 统一使用绝对路径 `/assets/yugioh/font/xxx.ttf`

### 问题 2：EXE 启动器缺失
**现象：** public 包中无 exe 文件  
**原因：** 原打包脚本未包含 exe 复制逻辑  
**解决：** 在 `build-public.cjs` 中添加自动复制流程

### 问题 3：移动端按钮点击不灵敏
**现象：** 小按钮触控失败率高  
**原因：** 触控热区小于 44×44px  
**解决：** 使用 `::before` 伪元素扩展热区

### 问题 4：横屏时界面元素重叠
**现象：** 高度不足时组件遮挡  
**原因：** 未针对横屏优化布局  
**解决：** 添加 `@media (orientation: landscape)` 媒体查询
