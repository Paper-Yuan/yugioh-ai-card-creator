## 🐛 已知问题和限制

1. **AI生成依赖网络**：需要稳定的网络连接
2. **浏览器兼容性**：推荐Chrome、Edge、Firefox最新版
3. **LocalStorage限制**：通常5-10MB，卡片过多可能受限
4. **Canvas限制**：部分老旧浏览器不支持Canvas API
5. **移动端性能**：低端设备可能略慢
