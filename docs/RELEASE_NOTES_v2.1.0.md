## 🎉 主要更新

### ✨ Phase 1A：全新效果选择器 UI

全新的模块化效果选择器，替代传统下拉菜单，提供更流畅的设计体验。

**新增功能：**
- 🔍 **实时搜索**：支持中英文关键词搜索（如"检索"、"search"、"特召"）
- 📂 **智能分类**：9 大效果分类自动折叠，快速定位目标效果
- 🕐 **最近使用**：自动记录最近使用的 5 个效果模块（LocalStorage 持久化）
- 🎨 **现代化 UI**：毛玻璃效果、流畅动画、完整响应式适配
- 📱 **移动端优化**：虚拟键盘自适应、触摸友好的交互

**新增文件：**
- `effect-wizard.css` (456行) - 完整的效果选择器样式系统
- `module-selector.js` (350行) - 模块选择器管理器
- `conditional-display.js` (380行) - 条件显示与参数验证
- `module-selector-init.js` (165行) - 初始化与集成脚本

### 🚀 Phase 1B：P0 效果模块补全

新增 **3 个关键效果模块**，覆盖 **1,919 张卡片**：

#### 1. **to_deck** - 返回卡组 (726张卡)
- 支持返回到卡组**顶部/底部/洗入**三种位置
- 支持从手卡/墓地/除外区/场上多种来源返回
- 标准 `SEQ_DECK*` 常量实现，完全兼容 YGOPro

**典型卡片示例：**
- 「PSY 骨架王·Ω」- 除外区返回卡组顶部
- 「月之书」- 场上卡片洗入卡组
- 「强欲而谦虚之壶」- 挖掘后返回卡组底部

#### 2. **token_summon** - 衍生物生成完整版 (236张卡)
- **完整参数支持**：ATK/DEF/等级/种族/属性/表示形式
- 支持**批量生成**多个衍生物
- 支持**攻击限制**（当回合不能攻击/直接攻击）
- 使用标准 `Duel.CreateToken` 实现

**典型卡片示例：**
- 「替罪羊」- 生成 4 只羊衍生物（守备表示）
- 「幻影骑士团 断碎剑」- 生成 2 只暗属性战士族衍生物
- 「流天类星龙」- 生成等级可变的流星衍生物

#### 3. **attach_xyz_material** - 超量素材附加 (新机制)
- 支持 5 种来源区域（手卡/墓地/除外/卡组/场上）
- 可附加到**自身**或**场上其他超量怪兽**
- 完整的 `Duel.Overlay` 逻辑实现

**典型卡片示例：**
- 「No.101 寂静荣誉方舟骑士」- 吸收对方怪兽作为素材
- 「超量单元」- 从墓地/除外将怪兽附加为素材
- 「RUM-七皇之剑」- 超量升阶时附加原素材

### ⚡ Phase 2：动态数值系统扩展

扩展 `value-source-generator.ts`，新增 **8 种动态数值源**，预计覆盖 **2,700+ 张卡片**：

| 数值源 | 说明 | 典型卡片示例 |
|--------|------|--------------|
| **生命值差值** | 双方基本分差值的一半/全部 | 「伤害慢跑者」「神圣生命防护罩」 |
| **战斗伤害关联** | 战斗造成的伤害数值 | 「武器商人」「战斗吃货」 |
| **除外区计数** | 双方除外区的卡片总数×倍率 | 「次元之壁」「不同次元的管理者」 |
| **手牌数差值** | 对方手牌数－自己手牌数 | 「手牌断绝」「断绝之链」 |
| **回合数关联** | 回合数×倍率 | 「时间机器」「命运之轮」 |
| **卡组剩余数** | 卡组剩余卡片数量×倍率 | 「图书馆的魔导书」「卡库罗的蜜饯」 |
| **代价数量** | 作为 cost 送去墓地的卡片数量×倍率 | 「凤凰神的羽毛」「墓穴的指名者」 |
| **增强控制器** | 支持自己/对手/双方的精细化计数 | - |

## 🚀 使用方法

### 体验新功能

1. **启动应用**
   ```bash
   解压后双击运行 启动游戏王制卡器.bat
   # 或在浏览器访问 http://localhost:3000
   ```

2. **使用效果选择器**
   - 进入"效果向导"步骤
   - 点击"切换到模块选择器"按钮
   - 尝试搜索：输入"检索"、"特召"、"token"等关键词
   - 点击分类头部可展开/收起效果列表

3. **使用新增 P0 模块**
   - 搜索"返回卡组"→ 选择 `to_deck` 模块
   - 搜索"衍生物"→ 选择 `token_summon` 模块
   - 搜索"超量素材"→ 选择 `attach_xyz_material` 模块
